# We Heralds Of Freedom — Internal Repository

Internal, version-controlled companion repository for the manuscript *We Heralds Of Freedom: An
Arcane Keys Novella*, by Wilbert Tien (Draft Zero).

## Structure

- **`manuscript/`** — The manuscript itself, split out of the source `.docx` into one
  version-controlled, diffable Markdown file per section (front matter, Chapters One through Eight,
  Epilogue, Glossary), with formatting (bold/italic) preserved. `manuscript/INDEX.md` documents the
  exact paragraph-range boundaries used to split the source file, so the split can be reproduced or
  re-verified against any future draft.
- **`story-bible/`** — Continuity-reference notes compiled from a full, sequential, word-for-word
  read of Draft Zero (not a summary pass): `characters.md`, `locations.md`, `magic-system.md`,
  `timeline.md`, and `expanded-glossary.md` (the author's own glossary, cross-referenced to where
  each term is actually used in the narrative, plus in-text terms the glossary doesn't yet cover).

These are reference/continuity materials for future drafting — they document what Draft Zero
currently says, not prescriptive canon.
